# iPhone での確認チェックリスト（約5分）

新しい版を本番に出す前に、**試作版**で確かめる。すべて「はい」なら合格。
ひとつでも「いいえ」なら、その番号と、できればスクリーンショットか画面収録を Claude に渡す。

試作版は本番とは別の保存場所を使うので、ここで書いたり消したりしても、ふだんの日記には影響しない。

## 準備
- [ ] 1. Safari で試作版のアドレスを開き、「共有」→「ホーム画面に追加」した（本番とは別のアイコンになる）

## 暦
- [ ] 2. 今月の和風月名・二十四節気・月の満ち欠けが表示される
- [ ] 3. 左右になでると月がめくれる。前の月で「今日」を押すと今月に戻る
- [ ] 4. 昼（ライトモード）と夜（ダークモード）で、色が切り替わる

## 書く（フリック入力）
- [ ] 5. 「書く」を押すと、すぐキーボードが出て、カーソルが末尾にある
- [ ] 6. フリックで打って変換する時、下線は **iPhone の普通の下線だけ**（線が二重になったり、ずれたりしない）
- [ ] 7. カーソルが打っている字の位置と合っている
- [ ] 8. 入力欄をタップすると「ペースト」が出せる。タップでキーボードが消えない
- [ ] 9. 10行以上書いても、重くならない。打っている行が隠れない
- [ ] 10. 上にフリック・下にスクロールしても、画面の部品が跳ねたり、ずれたりしない
- [ ] 11. キーボードが出ていても、スクロールしなくても「綴じる」と「暦」が押せる

## 書く（音声入力）
- [ ] 12. キーボードのマイクで話すと、字が手書き書体で入る

## 綴じる・読む
- [ ] 13. 初めて書いた日に「綴じる」と、暦に戻って朱印が押される
- [ ] 14. 日付を押すと、すぐ全文が手書きの揺らぎ付きで出る。「「」で行が終わっていない
- [ ] 15. 「なおす」で、続きから書ける
- [ ] 16. 全部消して「綴じる」と「白紙に戻しますか」が出る。「書き戻す」で元に戻る

## 保存・控え
- [ ] 17. アプリを完全に閉じて開き直しても、書いた日記が残っている
- [ ] 18. 機内モードでアプリを開いても起動する
- [ ] 19. 栞の「控えを書き出す」で、「ファイル」に保存できる

## 本番切り替えの時だけ
- [ ] 20. 切り替える前に、本番アプリの栞から控えを書き出した
- [ ] 21. 切り替えた後、本番アプリで、これまでの日記が全部見える
